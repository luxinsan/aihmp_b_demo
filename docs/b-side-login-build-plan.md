# 医护端登录页构建计划

## 目标

构建医护端（B 端）账密登录流程，并在登录成功后按账号绑定院区数量分流。

## 范围

- 只保留账密登录，不保留验证码登录。
- 账号凭证支持手机号和工号两类，通过表单内控件切换。
- 登录前必须勾选用户协议与隐私政策。
- 用户协议与隐私政策使用弹窗展示，占位文案先落地。
- 登录成功后：
  - 单院区账号直接进入系统首页（工作台）。
  - 多院区账号进入院区选择页，选择院区后进入工作台。
- 页面 logo、背景、登录素材、版权、协议内容和院区名称支持租户配置；选择院区列表不展示院区 logo。

## 可追踪任务

| 阶段 | 任务 | 产物 | 验收标准 | 状态 |
| --- | --- | --- | --- | --- |
| 1 | 确认登录页入口与工作台跳转 | `App` 登录前置状态 | 未登录展示登录页；登录成功进入现有工作台 | 已完成 |
| 2 | 建立租户配置模型与 mock 数据 | `loginTenantConfig` | logo、背景、素材、版权、协议、院区从配置读取 | 已完成 |
| 3 | 构建账密登录表单 | `PasswordLoginForm` | 手机号 / 工号切换；密码输入；无验证码入口 | 已完成 |
| 4 | 实现常规校验与反馈 | antd `Form` 校验 | 手机号格式校验；工号必填；密码必填；错误清晰 | 已完成 |
| 5 | 实现协议与隐私政策弹窗 | `AgreementModal` | 点击协议/隐私政策打开 `720` 宽弹窗，占位文案可读 | 已完成 |
| 6 | 实现登录成功分流 | 登录 handler | 单院区直进工作台；多院区进入院区选择 | 已完成 |
| 7 | 构建院区选择页 | `CampusSelectPanel` | 使用“院区”表述；可返回；点击院区进入工作台 | 已完成 |
| 8 | 视觉还原与响应式 | 登录页样式 | 贴近截图：顶部品牌栏、浅蓝背景、居中双栏卡片 | 已完成 |
| 9 | 验证 | 构建与浏览器检查 | 登录校验、弹窗、分流、工作台进入路径可用 | 已验证 |

## 组件拆分

```text
LoginPage
├── LoginBrandHeader
├── LoginShell
│   ├── LoginVisualPanel
│   └── PasswordLoginForm
├── CampusSelectPanel
└── AgreementModal
```

## 登录分流规则

```text
提交账密
-> 前端基础校验
-> 协议勾选校验
-> mock 登录
-> 账号绑定 1 个院区：进入工作台
-> 账号绑定多个院区：进入院区选择页
-> 选择院区：进入工作台
```

## 当前 mock 约定

- 手机号登录示例账号 `13411111111` / `13800000000` 绑定多个院区。
- 工号登录示例账号 `2001001` / `10001` 绑定单个院区。
- 密码统一使用 `123456` 作为 mock 成功密码。
- 其他组合返回账号或密码错误。
